The whole model on one page. Each row links to the guide section that explains it. New to this? Start with the tutorial.

The model in five lines

ConceptRule
ComponentA struct with data. Implements TypedComponent. NAME never changes.
SystemA fn(&SystemWorld, &mut SystemContext). Finds components by query, edits them. No captured state.
StageWhen a system runs: Start, FixedUpdate, Update, Gameplay, LateUpdate, Events.
CommandA request that leaves component data (spawn, destroy, sound, scene load). Applied when the stage ends.
Eventctx.emit(x) in frame N, ctx.events::<X>() in frame N + 1.

Skeleton: component, system, registration

use serde::{Deserialize, Serialize};
use zestengine_core::ecs::{ObjectContext, Stage, run_ordered};
use zestengine_core::{ComponentRegistry, MotionContext, TypedComponent};

#[derive(Serialize, Deserialize)]
pub struct Spinner {
    pub degrees_per_second: f32,   // saved in the scene, editable in the inspector
    #[serde(skip)]
    pub elapsed: f32,              // runtime only
}

impl Default for Spinner {
    fn default() -> Self { Self { degrees_per_second: 45.0, elapsed: 0.0 } }
}

impl TypedComponent for Spinner {
    const NAME: &'static str = "Spinner";
}

impl Spinner {
    fn update(&mut self, obj: &mut ObjectContext<'_, '_>) {
        self.elapsed += obj.dt;
        // obj.translation(), obj.set_translation(..), obj.input, obj.emit(..), obj.destroy_self() ...
    }
}

pub fn register(registry: &mut ComponentRegistry) {
    registry.register_ecs::<Spinner>();
    registry.register_system_for::<Spinner>("game::spinner", Stage::Update, |world, ctx| {
        run_ordered(world, ctx, Spinner::update)
    });
}

Registration variants: register_system, register_system_for::<T>, register_system_if. Use register_system_for::<T> by default: it costs nothing while no enabled T exists.

When something goes wrong

SymptomUsual cause
Panic: … already borrowedTwo borrows of one component type, one mutable.
Panic: structural ECS access while component views are borrowedYou tried to spawn, remove or despawn inside a system. Queue a command.
System never runsNot registered, no enabled T for register_system_for::<T>, or the object is inactive.
Event never arrivesIt is readable the next frame, never the same frame.
Object in the wrong place under a parentA world position written to the local Transform. Use set_world_position.
