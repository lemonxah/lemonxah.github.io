1//! [`EcsMoveHost`], the per-object helper every native game system uses.
2//!
3//! Local transforms and sibling component data stay authoritative in the ECS. Reads return checked borrow
4//! guards; data edits release their checked borrow before returning. Everything a game developer needs to
5//! know (immediate versus queued calls, frame order, targets, local versus world space) is documented on
6//! [`EcsMoveHost`] itself.

13/// Everything a native game system can do to the world, bound to one object (called "self" below).
14///
15/// A native system is a function the engine runs once per frame stage ([`Stage`](super::Stage)). The usual way
16/// to write one is [`run_ordered`](super::run_ordered): it calls your closure once for every active instance of
17/// a component, in the scene's authoring order, and passes it the component (`&mut T`) plus an `EcsMoveHost`
18/// bound to the object that owns that instance. Through the host you read and edit other objects, move things,
19/// spawn and destroy, push physics bodies, play sounds, save, switch scenes and use the network.
20///
21/// **Guides:** the [Engine API Guide](https://lemonxah.github.io/zestengine/docs/ENGINE_API.html) walks through
22/// this type by task (moving things, spawning and destroying, physics, input, audio, networking, with recipes),
23/// and the [ECS Guide](https://lemonxah.github.io/zestengine/docs/ECS.html#the-comfortable-way-run_ordered-and-ecsmovehost)
24/// explains where it fits in the system model.
25///
26/// ```ignore
27/// use zestengine_core::ecs::{EcsMoveHost, Stage, SystemContext, SystemWorld, run_ordered};
28/// use zestengine_core::{ComponentRegistry, MoveHost, ObjectRef, TypedComponent};
29///
30/// #[derive(Default, Serialize, Deserialize)]
31/// struct Chaser { target: ObjectRef, speed: f32 }
32/// impl TypedComponent for Chaser { const NAME: &'static str = "Chaser"; }
33///
34/// fn chase(world: &SystemWorld<'_>, ctx: &mut SystemContext<'_>) {
35///     run_ordered(world, ctx, |chaser: &mut Chaser, host: &mut EcsMoveHost<'_, '_>| {
36///         // World position of the target, or None when the reference is unset or the object is gone.
37///         let Some(goal) = host.position_of(chaser.target) else { return };
38///         let here = host.world_position();                        // `MoveHost`: world position of self
39///         let step = (goal - here).normalize_or_zero() * chaser.speed * host.dt; // `dt` comes from `SystemContext`
40///         host.set_world_position(here + step);                    // immediate: later systems see the move
41///     });
42/// }
43///
44/// fn register(registry: &mut ComponentRegistry) {
45///     registry.register_ecs::<Chaser>();
46///     registry.register_system_for::<Chaser>("game::chase", Stage::Update, chase);
47/// }
48/// ```
49///
50/// # What a call does, and when
51///
52/// Every method is one of three kinds, and its documentation says which one it is.
53///
54/// | Kind | Which methods | When you see the result |
55/// | --- | --- | --- |
56/// | **Immediate** | Reads, and writes that edit native component data in place: [`edit`](Self::edit), [`set_local_transform`](Self::set_local_transform), [`set_world_transform_of`](Self::set_world_transform_of), [`set_world_position_of`](Self::set_world_position_of), [`set_destination`](Self::set_destination), [`stop_agent`](Self::stop_agent), [`emit_particles`](Self::emit_particles), the local copy written by [`set_net_var`](Self::set_net_var), and the [`MoveHost`] setters such as `set_translation` and `set_animator_bool`. | At once: on the next line, and in every system that runs later in the same stage. |
57/// | **Queued** | Anything that pushes a [`ComponentCommand`] for the engine: spawning, [`destroy`](Self::destroy), [`set_active`](Self::set_active), [`add_impulse`](Self::add_impulse), [`set_velocity`](Self::set_velocity), [`move_character`](MoveHost::move_character), sounds, saves, [`modify_material`](Self::modify_material), time scale, language, and the local half of networked spawns. | When the current stage is over. The engine applies the queued commands in the order they were pushed, after every system of the stage has run and before the next stage starts. |
58/// | **Queued (host)** | Commands the play session does not handle itself but returns to the application hosting the game (the player or the editor): scene loads, [`quit`](Self::quit), cursor lock, input rebinding, RPCs, ownership requests, and the replication half of networked spawns and variables. | After the frame's last stage. The host applies them at the end of the frame. |
59///
60/// Spawn methods return the new [`ObjectId`] immediately, but the object only exists once its command has been
61/// applied, which is the next stage. Until then reads such as [`get`](Self::get) or
62/// [`transform_of`](Self::transform_of) find nothing for that id. Commands you queue *after* a spawn and aim at
63/// the new id (for example [`set_active`](Self::set_active)) are applied after it, in order, and do find it.
64/// Physics is the exception: a rigid body is created at the next physics sync, so an impulse or velocity aimed
65/// at an object spawned (or re-enabled) in the same stage is silently dropped.
66///
67/// # Frame order
68///
69/// A frame runs these stages in order. A system sees everything systems of earlier stages did, because queued
70/// commands are applied between stages.
71///
72/// 1. `Start`: objects that just became active run their start-up systems (once per object).
73/// 2. `FixedUpdate`: zero or more times per frame at a fixed time step, each followed by a physics step.
74/// 3. `Events`: collision, trigger and animation-event callbacks.
75/// 4. `Update`, then `Gameplay`, then `LateUpdate`. The commands of `Update` are applied before `Gameplay`
76///    runs, so weapons, cameras and the like see positions after movement and physics corrections. Navigation
77///    agents and animation advance between `Gameplay` and `LateUpdate`.
78///
79/// See [`Stage`](super::Stage) for the stage list. Systems of one stage run one after another (never in
80/// parallel), so an immediate write by an earlier system is visible to a later one.
81///
82/// # Targets
83///
84/// Methods that act on another object take `impl Into<ObjectRef>`: an [`ObjectRef`] (the field type you put on a
85/// component and wire up in the inspector) or a bare [`ObjectId`]. A few methods take an [`ObjectRef`] only,
86/// because they predate this convention; their docs say so, and an [`ObjectId`] converts with `.into()`.
87///
88/// * Reads and in-place edits resolve the target with [`entity_of`](Self::entity_of). An unset reference, an id
89///   no object has (never spawned, already destroyed, or spawned this stage and not applied yet), or an entity
90///   that is not a scene object gives `None`, `false` or a no-op; it is not an error.
91/// * Queued methods only check that the reference is set. The object is looked up when the command is applied;
92///   if it has gone by then, the command does nothing.
93/// * A **disabled** (inactive) object is still a valid target for reads and edits. Use
94///   [`is_active`](Self::is_active) to ask whether it is running.
95///
96/// # Local and world space
97///
98/// [`translation`](MoveHost::translation), [`rotation`](MoveHost::rotation) and [`scale`](MoveHost::scale) (from
99/// [`MoveHost`]) are the object's own **local** values, relative to its parent. [`self_transform`](Self::self_transform),
100/// [`transform_of`](Self::transform_of), [`matrix_of`](Self::matrix_of), [`position_of`](Self::position_of) and
101/// [`world_position`](MoveHost::world_position) are **world** values. The `set_world_*` methods take world values
102/// and convert them through the parent chain; [`set_local_transform`](Self::set_local_transform) writes the local
103/// fields directly. World values are computed from the live local transforms, so they include moves made earlier
104/// in the same stage.
105///
106/// # Borrow rules
107///
108/// Component data is borrowed with hecs' checked borrows, one component column at a time. Asking for a component
109/// type that is already mutably borrowed panics (hecs reports `already borrowed`). The usual way to trigger that:
110///
111/// * requesting the same component type `T` that the running [`run_ordered`](super::run_ordered) system is
112///   iterating, for example `ctx.get::<Health>(other)` from inside a `Health` system (the system already holds
113///   `&mut Health`);
114/// * calling [`edit`](Self::edit) for a type while a [`Ref`] guard of that type from [`get`](Self::get) is still
115///   alive.
116///
117/// Read sibling components of *other* types, copy what you need out of a guard and drop it, or collect ids first
118/// and act afterwards.
119///
120/// # What you get through `Deref`
121///
122/// `EcsMoveHost` derefs (also mutably) to [`SystemContext`], so the frame's data is available on the host itself:
123///
124/// * `dt`: seconds this stage advances game time, scaled by the time scale (the fixed step during `FixedUpdate`);
125///   `unscaled_dt`: real seconds, unaffected by [`set_time_scale`](Self::set_time_scale), for UI and pause menus.
126/// * `time`: scaled game seconds since play began; `water_time`: the water animation clock (synchronised between
127///   peers in a network game).
128/// * `input`: this frame's [`InputState`](crate::InputState), for example `ctx.input.down("Fire")`,
129///   `pressed`, `released`, `axis`, `axis2` and `mouse_delta`.
130/// * `commands`: the command queue itself. Push a [`ComponentCommand`] directly for anything that has no helper
131///   here, such as [`ComponentCommand::AddForce`], [`ComponentCommand::PlayAudio`],
132///   [`ComponentCommand::AssignMaterial`], [`ComponentCommand::NetDespawn`] or
133///   [`ComponentCommand::NetLoadScene`].
134/// * `services`: the borrowed frame services ([`SystemServices`](super::SystemServices): `physics`, `nav`, `net`,
135///   `screen`, `materials`, `save`, `strings`, `time_scale`, `events`, `scene_events`, ...). The helpers on this
136///   type wrap them and fall back to `None`, `false` or a default when a service is missing, as in a headless run.
137/// * [`events::<E>()`](SystemContext::events): the events of type `E` emitted during the previous frame, and
138///   [`emit`](SystemContext::emit): queue an event that every system reads next frame.
139/// * [`is_visible`](SystemContext::is_visible), [`order_key`](SystemContext::order_key) and
140///   [`instance_order`](SystemContext::instance_order): lower-level helpers for hand-written queries.
141///   (`SystemContext::is_active` takes a world and an entity; the host's own
142///   [`is_active`](Self::is_active) takes an object reference and shadows it.)
143///

230/// ## Networking
231///
232/// *Authority* is the right to simulate an object and publish its state. In a session it belongs to the object's
233/// owner peer, or to the host for an object nobody owns; see [`has_authority`](Self::has_authority). A copy that
234/// another peer simulates is *driven remotely* ([`driven_remotely`](Self::driven_remotely)): local input must not
235/// move it. **Offline (no session) every networking method behaves as local**: you have authority over
236/// everything, [`connected`](Self::connected), [`is_server`](Self::is_server) and
237/// [`is_client`](Self::is_client) are `false`, [`local_peer`](Self::local_peer) is `0`, networked spawns create a
238/// plain local object, and [`rpc_self`](Self::rpc_self) loops back to the caller.
239///
240/// * State: [`connected`](Self::connected), [`is_server`](Self::is_server), [`is_client`](Self::is_client),
241///   [`local_peer`](Self::local_peer), [`peers`](Self::peers), [`net_view`](Self::net_view),
242///   [`has_authority`](Self::has_authority), [`driven_remotely`](Self::driven_remotely).
243/// * Ownership: [`request_ownership_of`](Self::request_ownership_of).
244/// * Variables and calls: [`set_net_var`](Self::set_net_var), [`set_net_var_self`](Self::set_net_var_self),
245///   [`rpc_self`](Self::rpc_self), [`rpcs_for_self`](Self::rpcs_for_self).
246/// * Spawning: [`net_spawn`](Self::net_spawn), [`net_spawn_server`](Self::net_spawn_server),
247///   [`net_clone`](Self::net_clone), [`net_spawn_with`](Self::net_spawn_with).
248pub struct EcsMoveHost<'world, 'frame> {
249    /// The ECS world this system call runs against.
250    ///
251    /// Use it for direct component access to the owner (`host.world.get::<T>(host.owner)`) or for custom
252    /// `world.query` loops. Unlike [`get`](Self::get) and [`edit`](Self::edit) it applies no visibility check. The same
253    /// borrow rules apply: see "Borrow rules" on [`EcsMoveHost`].
254    pub world: &'world SystemWorld<'world>,
255    /// The object this host acts for ("self"): the object that owns the component instance being updated.
256    ///
257    /// This is a hecs handle, valid for the current call only. Use [`self_id`](MoveHost::self_id) when you need a
258    /// persistent [`ObjectId`] to store or compare.
259    pub owner: Entity,
260    /// The frame's shared context, reached through [`Deref`].
261    context: &'world mut SystemContext<'frame>,
262}
263
264impl<'world, 'frame> EcsMoveHost<'world, 'frame> {
265    /// Binds a host to the object `owner` for the duration of one system call.
266    ///
267    /// Game code rarely calls this: [`run_ordered`](super::run_ordered) builds one host per active component
268    /// instance. Build your own in tests, or when a system walks objects by hand with `world.query`, passing the
269    /// [`SystemContext`] the engine gave you.
270    ///
271    /// # Panics
272    ///
273    /// `owner` must be a scene object (an entity with an [`ObjectId`] and a [`Transform`]). The [`MoveHost`]
274    /// methods (`self_id`, `translation`, ...) panic for any other entity.
275    pub fn new(world: &'world SystemWorld<'world>, owner: Entity, context: &'world mut SystemContext<'frame>) -> Self {
276        Self { world, owner, context }
277    }
278    /// Whether another peer, not this machine, is currently simulating this object.
279    ///
280    /// True only when all of these hold: a network session is [`connected`](Self::connected), the object has a
281    /// [`NetworkObject`](crate::NetworkObject) or [`Sync`](crate::Sync) component, and the local peer lacks
282    /// [authority](Self::has_authority) over it. Input-driven systems (character controllers, weapons) return early
283    /// when this is true, so the local keyboard does not move a copy that belongs to someone else.
284    ///
285    /// **Immediate.** Always `false` offline and for objects that are not networked.
286    pub fn driven_remotely(&self) -> bool {
287        self.services.net.is_some_and(|net| net.connected
288            && (self.world.get::<crate::NetworkObject>(self.owner).is_some() || self.world.get::<crate::Sync>(self.owner).is_some())
289            && !net.has_authority(self.self_id()))
290    }
291    /// The **world** transform of this object (position, rotation and scale decomposed from its world matrix).
292    ///
293    /// **Immediate.** Computed from the live local transforms, so it includes moves made earlier in this stage by
294    /// you or by other systems. For the local fields use [`translation`](MoveHost::translation),
295    /// [`rotation`](MoveHost::rotation) and [`scale`](MoveHost::scale); for just the world position,
296    /// [`world_position`](MoveHost::world_position).
297    pub fn self_transform(&self) -> Transform { Transform::from_matrix(self.world()) }
298    /// Resolves an object reference to its ECS [`Entity`], or `None` if the object cannot be used.
299    ///
300    /// This is the gate in front of [`get`](Self::get), [`edit`](Self::edit), [`transform_of`](Self::transform_of),
301    /// [`is_active`](Self::is_active) and the other read and edit methods. It returns `None` when
302    ///
303    /// * the reference is unset;
304    /// * no object has that id (never spawned, already destroyed, or spawned this stage and not applied yet);
305    /// * the entity is not *visible*. Visible means the entity is a scene object (it carries an [`ObjectId`]) and,
306    ///   when the scene supplies an authoring order, is listed in it. The helper entities that hold the second and
307    ///   later copy of a duplicated component are not objects and never resolve.
308    ///
309    /// Visible does not mean active: a disabled object resolves normally; ask [`is_active`](Self::is_active) whether
310    /// it runs. The returned [`Entity`] is a runtime handle for this call only; store [`ObjectId`] or [`ObjectRef`]
311    /// values instead.
312    pub fn entity_of(&self, target: impl Into<ObjectRef>) -> Option<Entity> {
313        let entity = self.world.entity(target.into().id()?)?;
314        self.context.is_visible(self.world, entity).then_some(entity)
315    }
316    /// Reads component `T` of another object.
317    ///
318    /// Returns a checked borrow guard ([`Ref`], which derefs to `&T`) for the object's primary instance of `T`, or
319    /// `None` if the target does not resolve (see [`entity_of`](Self::entity_of)), has no `T`, or has its `T` switched
320    /// off. Additional duplicate instances of `T` on the same object are not reachable through `get`.
321    ///
322    /// **Immediate.** It sees every in-place edit made earlier in this stage. Keep the guard short-lived: it holds a
323    /// shared borrow, so editing or mutably borrowing the same component type while it is alive panics (see "Borrow
324    /// rules" on [`EcsMoveHost`]). Copy out what you need and let the guard drop.
325    ///
326    /// # Examples
327    ///
328    /// ```ignore
329    /// // Read, then release the borrow before doing anything else with the host.
330    /// let hp = ctx.get::<Health>(self.target).map(|health| health.current);
331    /// if hp.is_some_and(|hp| hp < 10.0) {
332    ///     ctx.play_sound_at("audio/low_health.wav", ctx.self_transform().translation, 1.0);
333    /// }
334    /// ```
335    pub fn get<T: DataComponent>(&self, target: impl Into<ObjectRef>) -> Option<Ref<'_, T>> {
336        self.world.get::<T>(self.entity_of(target)?)
337    }
338    /// Reads component `T` of this object, without the visibility check of [`get`](Self::get).
339    ///
340    /// Returns `None` if the object has no enabled `T`. **Immediate.**
341    ///
342    /// Use it for *sibling* components of a different type than the one your system iterates. Never ask for that
343    /// type itself: [`run_ordered`](super::run_ordered) already holds `&mut T` for it, and a second borrow of the same
344    /// type panics.
345    ///
346    /// # Examples
347    ///
348    /// ```ignore
349    /// // A weapon system reading another component on the same object.
350    /// let held = ctx.get_self::<Grabbable>().is_some_and(|grab| grab.held);
351    /// ```
352    pub fn get_self<T: DataComponent>(&self) -> Option<Ref<'_, T>> { self.world.get::<T>(self.owner) }
353    /// Changes component `T` of another object in place by running `edit` on it.
354    ///
355    /// Returns `true` if the closure ran, `false` if the target does not resolve (see
356    /// [`entity_of`](Self::entity_of)) or has no enabled `T`.
357    ///
358    /// **Immediate.** The closure runs before `edit` returns, with exclusive access to the live data, and later
359    /// systems of the same stage see the result. Nothing is queued. The closure only receives the component, so
360    /// compute anything that needs the host beforehand. Panics if `T` is already borrowed (see "Borrow rules" on
361    /// [`EcsMoveHost`]), for example while you hold a [`Ref`] of the same type from [`get`](Self::get).
362    ///
363    /// # Examples
364    ///
365    /// ```ignore
366    /// // Hurt whatever the ray hit, if it has Health.
367    /// let damage = 25.0;
368    /// let hurt = ctx.edit::<Health>(hit.object, move |health| { health.apply_damage(damage); });
369    /// ```
370    pub fn edit<T: DataComponent>(&self, target: impl Into<ObjectRef>, edit: impl FnOnce(&mut T)) -> bool {
371        let Some(entity) = self.entity_of(target) else { return false };
372        let Some(mut value) = self.world.get_mut::<T>(entity) else { return false };

1227    /// limits). **Offline** there are no other peers, so the call is looped back to yourself as an event instead of a
1228    /// command: it reaches [`rpcs_for_self`](Self::rpcs_for_self) from the next frame, with `from == 0`, for every

1242        } else {
1243            self.commands.push(ComponentCommand::NetRpc { object, name: name.to_owned(), args, target, reliable: true });
1244        }
