Module avatar_oscquery 

Source
Expand description

OSCQuery for the avatar OSC bridge: the JSON tree that tells tools which /avatar/parameters/... addresses exist, a tiny HTTP responder for it, and the mDNS announcement (_oscjson._tcp and _osc._udp) that lets tools such as VRCFaceTracking find the ports without typing them in. No sockets here (the engine’s avatar_osc_host owns them); everything is bytes in and bytes out so it can be tested.

The tree follows the public OSCQuery proposal (FULL_PATH, ACCESS 0-3, TYPE tags i f T, VALUE, HOST_INFO), the same shape VRChat’s avatar tree has, so existing tools read it unchanged.
