Module spline 

Source
Expand description

Pure geometry of sprite shapes: bezier tessellation with an error bound and a point cap, polygon area / orientation, ear-clipping triangulation, polygon offset and Douglas-Peucker simplification. No scene, no GPU.

simplify
Douglas-Peucker. An open polyline keeps both ends; a closed ring is split at its two farthest-apart vertices so it never collapses. Every dropped vertex stays within tol of the result.
tessellate
Tessellate a spline. Straight segments stay one piece. max_points bounds the vertex count: the adaptive tolerance is doubled (and the fixed detail reduced) until the result fits, down to one piece per segment, so the cap can only be exceeded by a spline with more control points than the cap. Vertices closer than 1e-5 are merged.
triangulate
Ear-clipping triangulation of a simple polygon (no holes) in either orientation. Returns CCW triangles as indices into pts. Collinear vertices are dropped; a self-intersecting ring still terminates (the least-bad ear is clipped) but its fill is wrong where it crosses itself.
triangulate_with_holes
Triangulate outer minus holes: each hole is joined to the outer ring by a zero-width bridge (two coincident edges), holes taken left to right, and the single weakly simple ring is ear clipped. A hole with no valid bridge (outside the outer ring, crossing it) is skipped. Returns the ring’s vertices (bridge ends duplicated) and CCW triangles into them, so the triangle area equals the outer area minus the holes’ (for holes that do not overlap each other).
