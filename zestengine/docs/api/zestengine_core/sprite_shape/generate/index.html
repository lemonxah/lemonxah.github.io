Module generate

Spline + profile -> sprite-shape mesh (2D-8), and the collider outline.

§Pipeline (one pass, in this order)

  1. Tessellate the spline (super::spline::tessellate).
  2. Fill (closed shapes): triangulate the outline (offset by the profile’s fill_edge_offset), UVs from local position / the fill texture’s size in world units (tiling), or the sprite stretched over the bounds. Holes are not supported.
  3. Edges: the outline is walked clockwise (a counter-clockwise ring is reversed; flip_edge reverses again) so the left normal points out of the shape. Every segment gets the angle range its normal angle selects (super::select_range); consecutive segments with the same range and no corner form a run. A run is cut into tiles (plan_tiles, the stretch / fit maths) and each tile is a strip of quads that follows the curve, thickness = sprite height x point height, UV u linear in arc length across the tile.
  4. Corners: a control point that may be a corner and turns more than the threshold breaks the run; the profile’s outer / inner corner sprite is centred on the corner along the bisector. Without a corner sprite the two runs join with a (length-limited) miter instead.
  5. Caps (open shapes): start / end cap sprites placed beyond the ends.

Output is one MeshGroup per (fill | edge, texture), each a plain position / UV / u16 index list in object-local units (UV v is top-down like the sprite pool’s meshes). Within a group fill triangles come first, then edge strips, then corners, then caps (later draws over earlier).
