zestengine_core::sprite_shape

Module presets 

Source
Expand description

Starter profiles and splines for Sprite Shapes. A preset fixes the structure (angle ranges, open or closed, fit mode, corner behaviour) and leaves the sprite slots empty: the sprites belong to the project, so the user drops theirs onto the slots afterwards.
