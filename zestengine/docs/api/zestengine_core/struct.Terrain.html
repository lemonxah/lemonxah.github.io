Expand description

Heightfield terrain: a square, procedurally tessellated mesh whose vertex heights come from a (resolution + 1)² grid. The engine builds the render mesh and (optionally) a heightfield collider from this in Play; the component itself stores only data, so it serializes cleanly.

Fields§

§water_layers: bool

Compose water/river/island layers over the authored height grid.

§water_layer: Option<TerrainWaterLayer>

Resolved layer output; authored heights remain untouched and saved.

§size: f32

World-space X/Z extent of the square, in meters.

§resolution: u32

Quads per side; the height grid has (resolution + 1)² entries.

§heights: Vec<f32>

Vertex heights in meters, row-major over Z then X (heights[z * (resolution + 1) + x]), length (resolution + 1)².

§material: String

Project-relative .material path (“” = project default).

§heightmap: String

Project-relative heightmap image to import into heights (PNG, JPG, EXR or HDR; luminance is used). Empty = no source (sculpted heights).

§heightmap_scale: f32

Metres the heightmap’s full 0..1 luminance range spans.

§heightmap_offset: f32

Metres added to the imported height (0..1 black is at this height).

§heightmap_imported_path: String

The heightmap source the heights were last imported from (“” = none), so changing the source re-imports. Not meant to be edited by hand.

§heightmap_imported_scale: f32

The scale/offset the last import applied; changing them re-imports.

§heightmap_imported_offset: f32§texture_weights: Vec<[f32; 4]>

Per-vertex painted texture-layer weights (RGBA = up to 4 layers), row-major over Z then X like heights. Empty means “not painted yet” and defaults to layer 0 at runtime/editor.
