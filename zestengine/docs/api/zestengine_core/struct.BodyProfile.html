Expand description

The player’s body, saved per user (shared by every game): measurements, tracker roles and the T-pose the tracker offsets are solved from.

Fields§

§measured_eye_height: Option<f32>

Standing eye height from the last measurement (m).

§height_override_cm: Option<f32>

The player’s own height entry (cm, to the top of the head); wins over the measurement.

§arm_span: Option<f32>

Hand-to-hand distance in a T-pose (m).

§floor_offset: f32

Play-area floor correction (m), subtracted from every tracked height.

§auto_assign: bool

Assign tracker roles from the T-pose during a full calibration.

§roles: Vec<TrackerRole>

Role choices by device id (devices not listed keep their own role).

§tpose: Option<Vec<Option<StoredPose>>>

Stage-space tracker poses per slot at the last T-pose. Offsets are solved from it for whichever avatar is worn, so changing avatars needs no new T-pose.
