The ABI stamp of a component plugin (NET-3).

A plugin is a cdylib whose zestengine_register(&mut ComponentRegistry) takes Rust-ABI types. That is sound only when the plugin and its host were built by the same rustc, from the same engine version and dependency features, with the same debug_assertions and pointer width. A plugin proves it by exporting zestengine_plugin_abi (add zestengine_core::export_plugin_abi!(); to the crate); the host compares the stamp with its own before calling anything else. The stamp is plain #[repr(C)] data returned by an extern "C" function, so reading it is safe even when the other side is a different compiler.
