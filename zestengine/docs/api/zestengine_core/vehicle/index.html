Wheeled-vehicle physics: wheel suspension and a simple longitudinal drive model, plus the Vehicle component that reads the driving controls.

Structs§

Vehicle
A raycast-suspension wheeled vehicle. Put it on the same object as a dynamic crate::RigidBody (and a chassis collider held above the wheel contact points). Controls default to the First / Third Person Controller’s Move / Jump / Sprint actions, so the same WASD + Space + Shift scheme drives it: Move.y throttles and brakes (reverse), Move.x steers, Jump brakes and Sprint applies the handbrake.
Wheel
One wheel of a wheeled vehicle. Positions are in the vehicle object’s local space (metres), forward = local -Z.

Functions§

drive_force
Net longitudinal drive force (N). Throttle (0..1) accelerates; brake (0..1) decelerates against the current travel direction, so the vehicle can also reverse under brake.
suspension_force
Suspension force (N, up) for a wheel from its compression and compression velocity: the spring pushes back against compression, and the damper resists motion (adds force while compressing).
