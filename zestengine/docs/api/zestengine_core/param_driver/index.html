Module param_driver 

Source
Expand description

Parameter drivers: a state behaviour that changes Animator parameters when a state is entered (Set, Add, Random, Copy), so a controller can pick an outfit, count steps, roll a random idle or mirror one parameter into another without code.

The settings are stored on the state (AnimState::behaviour_settings, under the behaviour’s name) as RON text, so the controller file keeps one stable shape however many behaviour types exist; the behaviour parses them when they change, not every frame. The driver is registered under PARAMETER_DRIVER without any setup call.
