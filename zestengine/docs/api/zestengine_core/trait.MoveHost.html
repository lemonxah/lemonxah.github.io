impl MoveHost for EcsMoveHost<'_, '_>

The movement interface of the owner object, shared with the engine’s prediction replay (see MoveHost).

Reads and in-place writes here are immediate; move_character is queued. Besides the methods below, MoveHost provides world, world_position and set_world_position, which convert between this object’s local values and world space through parent_world.
