Module tile_object 

Source
Expand description

GameObject tiles (2D-5): a .tile whose game_object names a prefab puts one instance of it in every cell that uses the tile.

The instances are ordinary scene objects, children of the tilemap’s object, each carrying a TileObject that records the cell and the prefab it was made for (that is the per-cell storage: it is saved with the scene, so a loaded map finds its instances again and does not make them twice). The engine keeps them in step with the map (engine/src/scene/tile_objects.rs), in the editor and in play: painting a cell makes its instance, erasing the cell or changing its tile removes or replaces it, and undo of a stroke restores the map, after which the same step restores the instances. plan_tile_objects is that step’s pure core.
