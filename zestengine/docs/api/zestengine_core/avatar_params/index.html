Avatar parameters and expression-menu data.

AvatarParameters declares the typed values an avatar exposes (Bool / Int / Float, with a default, a saved flag and synced-or-local) and owns the runtime AvatarParamStore. The store is the avatar’s one parameter namespace: engine-filled built-ins (BuiltinParam) first, then the declared ones. It pushes only the values that changed since the last flush into the Animator’s parameter map, so a quiet avatar costs nothing per frame, and reads back what state-behaviour drivers wrote. AvatarMenuItem is the menu data (the hierarchy is the menu); the radial menu UI and the network sync are built on top of it elsewhere.

Sync budget: a Bool costs 1 bit, an Int or Float 8; only Synced parameters count (decision D6: 256 bits per avatar by default, set per project through ContentLimits::max_param_bits and per avatar through AvatarParameters::budget_bits).
