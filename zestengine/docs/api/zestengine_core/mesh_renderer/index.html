Module mesh_renderer 

Source
Expand description

Mesh Renderer / Skinned Mesh Renderer: the components that own how an object’s mesh is drawn (shadow casting, lightmap scale and ONE material per submesh slot).

The mesh itself is not here: it stays in the object’s ObjectSource (the “Mesh Filter” the inspector shows as a view). Slot k draws submesh k of that mesh. See docs/design/mesh-renderer-split.md.

Core has no dependency on assets or render, and an inline material snapshot carries render types, so MaterialSlot::Inline keeps the snapshot as opaque RON text that the engine decodes.
