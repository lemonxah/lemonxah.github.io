Module asset_ref 

Source
Expand description

Asset references by ID. An asset slot stores @<id> where the id is the stable GUID in the asset’s .meta sidecar (foo.physmat.meta), so moving or renaming the file (the editor carries the sidecar along) keeps every slot pointing at it. Plain paths from older files still resolve as paths.

The id -> path index is built per project root by scanning its .meta files once, kept current as the editor moves files, and rescanned when an id isn’t found.
