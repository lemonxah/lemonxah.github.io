Expand description

A request a system queues for the engine: spawn, destroy, push a body, play a sound, load a scene, save, talk over the network.

Systems edit component data directly; anything that reaches beyond it is queued here by pushing onto ecs::SystemContext::commands (or through the helpers on ecs::ObjectContext, which are usually nicer). The engine applies the queue, in order, when the stage that queued it finishes, after all checked ECS borrows have been released. A command that names an object that no longer exists is ignored. The play session applies most commands itself; session, window and content commands are handed on to the host application.

See Commands in the ECS guide, and the command reference in the Engine API guide for which helper queues which command.

SetActiveCamera(ObjectId)

Make this camera object the active render camera (2A).

§

SetLocalTransform

Write another object’s LOCAL transform (each field optional). The play session still applies it, but native systems do not need it: they edit the Transform in place, immediately, with ecs::ObjectContext::set_local_transform, which is visible to later systems in the same stage. Use this command only when you cannot reach the world (external tools).

Fields

§id: ObjectId

Target object.

§translation: Option<Vec3>

New local position in meters (None = keep).

§rotation: Option<Quat>

New local rotation (None = keep).

§scale: Option<Vec3>

New local scale (None = keep).

§

SetWorldTransform

Teleport: write another object’s WORLD position/rotation (each field optional). The engine converts to local using the object’s parent, so this is correct whether the target is a root or nested. Local-space writes use SetLocalTransform. As with that command, native systems should call ecs::ObjectContext::set_world_transform_of instead, which edits the transform in place and takes effect immediately.

Fields

§id: ObjectId

Target object.

§translation: Option<Vec3>

New world position in meters (None = keep).

§rotation: Option<Quat>

New world rotation (None = keep).

§

ModifyMaterialParams

Deferred edit of one material slot’s params: the engine applies the closure to the live params, writes the result back into the scene material, and refreshes the renderer’s copy after the pass.

Fields

Render slot index (0 = the main material).

§path: String
