Struct SceneWorld 

Source 
pub struct SceneWorld { /* private fields */ }
Expand description

Owns a scene’s ECS world and the index from saved ObjectIds to entities.

All structural operations (spawn, parent, insert and remove components, despawn) go through this type, so deleting an object can never leave a saved reference pointing at a reused slot. It is what editors, loaders and tests hold; game systems never see it. They receive a SystemWorld and queue ComponentCommands instead.

ⓘ
let mut scene = SceneWorld::new();
let player = scene.spawn("Player");
scene.insert(player, Health::default())?;
registry.run_systems(Stage::Update, &scene, &mut ctx);
assert_eq!(scene.get::<Health>(player).unwrap().current, 100.0);

See Testing systems in the ECS guide.

pub fn with_world<R>(&self, run: impl FnOnce(&SystemWorld<'_>) -> R) -> R

Run run with a SystemWorld over this scene: the same view a system receives. The world is locked exclusively for the duration, so component views (SceneWorld::get) must be released first and cannot be taken inside run (both panic). Use it for ad-hoc queries in tools and tests.

ⓘ
let total: f32 = scene.with_world(|world| {
    world.query::<&Health>().iter().map(|(_, hp)| hp.current).sum()
});

pub fn get<T: DataComponent>( &self, entity: Entity, ) -> Option<ComponentRef<'_, T>>

Borrow one component of one entity for reading. None if the entity has no T. The returned view holds a shared structural lock and a borrow lease on that slot until it is dropped: a conflicting borrow of the same slot, or any structural change, panics while it is alive.

Not available inside a running system (use the SystemWorld you were given).

Source

pub fn get_mut<T: DataComponent>( &self, entity: Entity, ) -> Option<ComponentMut<'_, T>>

Borrow one component of one entity for writing. Same rules as SceneWorld::get, with an exclusive lease on the slot. Independent entities can be borrowed mutably at the same time.
