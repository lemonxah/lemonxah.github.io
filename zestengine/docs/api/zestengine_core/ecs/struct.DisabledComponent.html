Struct DisabledComponent 

Source 
pub struct DisabledComponent<T: Component> { /* private fields */ }
Expand description

A disabled T, stored densely in its own typed ECS column. Queries for T see enabled instances; query this type explicitly to inspect disabled data. Authoring slots preserve their order and expose T through component_inner.
