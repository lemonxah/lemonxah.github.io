Expand description

Run update for every active instance of component T, in scene (authoring) order, handing it the component and an ObjectContext bound to the object.

Compared with a hand-written query loop it skips disabled objects (and anything under a disabled parent), iterates deterministically (so networked prediction and object-to-object interactions behave the same on every machine), and gives you the context helpers for moving, reading other objects, spawning, physics and more. Duplicate instances of T on one object each get a call, in inspector order.

The ordering collects and sorts the instances every call; for thousands of instances where order does not matter, a bare SystemWorld::query is cheaper.

impl Lifetime {
    fn update(&mut self, obj: &mut ObjectContext<'_, '_>) {
        self.seconds_left -= obj.dt;
        if self.seconds_left <= 0.0 { obj.destroy_self(); }
    }
}

registry.register_system_for::<Lifetime>("game::lifetime", Stage::Update, |world, ctx| {
    run_ordered(world, ctx, Lifetime::update)
});
