Typed ECS storage and the native system API shared by games, the editor, headless servers and plugins.

New here? Read the ECS Guide, which explains components, systems, stages, commands and events with tested examples, and the Engine API Guide for what a system can do (move, spawn, raycast, play sounds, save, network).

§The model

  • A scene object is a hecs entity. Its saved identity is an ObjectId; the hecs Entity is only a runtime handle.
  • A component is a TypedComponent value in a typed column. The first component of each type lives on the object’s own entity, so ordinary joined queries work. Further instances of the same type live on small auxiliary entities carrying an Owner that points back to the object.
  • A system is a SystemFn: it queries a SystemWorld and receives a SystemContext with time, input, services and a command queue. Systems are registered on the ComponentRegistry and run by Stage.
  • An entity template (EntityTemplate) is a registered, named, ready-made object that the editor lists under Create > Entity and systems spawn by name.

§Borrowing

Native systems use hecs’ checked column borrows: two borrows of one component type conflict when either is mutable, and the conflict panics. While a system runs, the owning SceneWorld holds exclusive structural access, so inserting, removing or despawning must be queued as a ComponentCommand instead. Editor-style component views (ComponentRef, ComponentMut) use checked entity/type leases and hold a shared structural lock, which is why the two access modes cannot overlap.

Structs§

Active
Whether an object is running: its Enabled flag and every ancestor’s. Computed by SceneWorld::propagate at stage boundaries, so it is a snapshot; SystemWorld::current_active answers for the present moment. Systems should skip objects that are not active (see SystemContext::is_active).
ComponentHandle
An owned entity/type lookup, allowing a component borrow to coexist with edits to unrelated scene-tree metadata. A borrowed value still prevents structural ECS changes until its view is released.
ComponentMut
Exclusive component access, scoped to one entity/type rather than an entire archetype. Independent instances can be edited together by editor tools.
ComponentRef
A borrowed component in the permanent ECS storage. Dropping the view releases both its component lease and the lock preventing archetype relocation.
ComponentSet
An object’s ordered component handles. Instances remain in shared typed ECS storage across frames, editor edits and subsystem queries.
ComponentSlot
Copyable authoring handle metadata, with native checked payload access. It owns no component value and remains valid only within its indexed scene.
ComponentType
Type-specific operations retain their originating plugin’s code. No cast by display name and no serialization is needed for storage, views or moves.
DisabledComponent
A disabled T, stored densely in its own typed ECS column. Queries for T see enabled instances; query this type explicitly to inspect disabled data. Authoring slots preserve their order and expose T through component_inner.
Enabled
An object’s own on/off switch (the checkbox in the inspector). It says nothing about the ancestors: Active is the inherited result that systems should respect.
Entity
Lightweight unique ID, or handle, of an entity
EntityTemplate
What a registered entity creates: a mesh shape plus the components a new instance starts with, in inspector order. Build one with EntityTemplate::new and EntityTemplate::with, and register it with ComponentRegistry::register_entity.
GlobalTransform
An object’s world matrix as of the last SceneWorld::propagate (the engine refreshes it at every stage boundary). It does not include transform writes made earlier in the current stage; SystemWorld::world_transform does.
Name
The display name of an object (the scene tree label). Cosmetic: names are not unique and may be empty, so refer to objects by ObjectId or ObjectRef instead.
NativeActionCall
NativeProperties
Reflection over the actual native world. During an action the executing instance is excluded, and other instances of its type are lent by that action’s query so same-archetype property reads remain borrow-safe.
ObjectContext
Everything a native game system can do to the world, bound to one object (called “self” below).
Owner
The object that a component instance belongs to. Object entities own themselves; the auxiliary entity holding a second instance of a component type points back at its object.
Parent
The object this one is parented to (None for a root). The parent link is authoritative data; the scene tree’s order is derived from it. Change it through SceneWorld::set_parent so cycles are rejected and the derived transforms are refreshed.
QueryBorrow
A borrow of a World sufficient to execute the query Q
QueryMut
A query builder that’s convertible directly into an iterator
Ref
Shared borrow of an entity’s component
RefMut
Unique borrow of an entity’s component
SceneWorld
Owns a scene’s ECS world and the index from saved ObjectIds to entities.
SystemContext
Everything a system needs besides the world: time, input, the command queue and the engine services for this frame.
SystemServices
Engine services lent to systems for one frame, without copying scene data.
SystemWorld
The world as a system sees it: queries and checked component access over the scene’s permanent typed storage.
