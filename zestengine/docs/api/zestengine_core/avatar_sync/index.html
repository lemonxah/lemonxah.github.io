Module avatar_sync 

Source
Expand description

Wire format for synced avatar parameters (P_AVPARAM).

Every peer wearing an avatar has the same declared parameters (they ship in the avatar package), so the packet carries no names: the schema is the synced parameters sorted by name, identified by a 32-bit hash of their names and kinds. A packet is [schema hash: u32 LE][payload], and the payload is one byte per Int / Float (Int 0..=255; Float -1..=1 as a signed byte over 127, the same quantisation remote copies show) followed by the Bools packed eight to a byte. A full 256-bit budget is therefore at most 32 payload bytes. A receiver whose schema hash differs (another version of the avatar) drops the packet instead of misreading it.

The codec is pure: it reads values from, and writes them to, plain slices or an AvatarParamStore through slots resolved once when the schema is built. SyncClock holds the send cadence: changes go out at 10 Hz, 30 Hz while a puppet is open, and the full state repeats every second so a lost packet or a late joiner catches up.
