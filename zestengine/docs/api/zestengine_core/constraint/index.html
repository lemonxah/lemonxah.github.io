Module constraint 

Source
Expand description

Transform constraints: an object follows one or more source objects by position, rotation, scale, a full parent link or by aiming at them.

The maths (solve_world) is pure and works on world matrices, so the same solver evaluates the Constraint component every frame at runtime and bakes constraints from a model file into plain animation curves at import (the importer reads FBX constraint nodes into ConstraintSpecs).

Semantics (this engine’s own, written from the FBX constraint attributes):

  • Position: the world position becomes the weighted mean of the sources’ positions (each moved by its offset) plus the constraint’s own offset.
  • Rotation: the weighted mean of the sources’ rotations, then the own offset.
  • Scale: the weighted mean of the sources’ world scales times the own offset.
  • Parent: the object keeps the per-source offset it was authored with and follows the weighted blend of source_world * offset (translation, rotation and, if enabled, scale), then the own offset.
  • Aim: the local aim axis turns towards the weighted mean source position; an up vector keeps the roll (scene up, a vector, towards a node or aligned with a node).

Every constraint has a total weight (0 = off, 1 = fully constrained: the result is blended from the unconstrained pose) and per-axis switches for translation, rotation (as XYZ Euler angles) and scale.
