Expand description

View of one material (standard or custom shader) as plain values.

Fields§

§name: String

Material name (the project-relative asset name).

§shader: String

“standard” or a project-relative .frag custom shader path.

§custom_values: Vec<f32>

Custom-shader property values, packed by property offset (16 floats once initialized; empty = take the shader’s defaults).

§base_color: [f32; 4]

Base albedo, linear RGBA.

§metallic: f32

Metalness 0 (dielectric) .. 1 (metal).

§roughness: f32

Perceptual roughness 0 (mirror) .. 1 (diffuse).

§occlusion_strength: f32

Ambient-occlusion map strength.

§toon_enabled: bool

Whether toon (cel) shading is on.

§toon_steps: f32

Toon band count (1 = flat).

§pbr_toon_blend: f32

PBR / toon blend, 0 = PBR .. 1 = toon.

§emission_enabled: bool

Whether emission is on.

§emission_color: [f32; 3]

Emissive colour, linear RGB.

§emission_intensity: f32

Emission multiplier (0 = off).

§alpha_mode: AlphaModeModel

How transparency is treated.

§alpha_cutoff: f32

Alpha-test threshold 0..1 in the Cutout mode.

§has_normal_texture: bool

A normal map is assigned to this material.

§normal_map_enabled: bool

Normal mapping is active.

§normal_strength: f32

Normal-map intensity.

§double_sided: bool

Render both faces (no back-face culling).

§blend_mode: BlendModeModel

Transparent blend equation (only used in the Transparent mode).

§cull_front: bool

Cull front faces (shows the inside of a mesh); ignored when double sided.

§grab: bool

Samples the opaque scene colour (refraction / blur / distortion shaders).

§stencil: StencilModel

Stencil test / write (Unity Stencil block); inactive by default.

§rim_color: [f32; 3]

Toon rim-light colour.

§rim_power: f32

Toon rim Fresnel exponent (higher = tighter edge).

§rim_strength: f32

Toon rim strength (0 = off).

§ramp_smoothness: f32

Toon cel-ramp edge softness.

§emission_scroll: [f32; 2]

Animated UV scroll for the emission map (uv units / second).

§emission_pulse: f32

Emission pulse speed (0 = steady); brightness oscillates.

§ao_invert: bool

Invert a split AO / Roughness / Metallic map (e.g. smoothness→roughness).

§roughness_invert: bool

Invert the roughness channel of a split map (e.g. smoothness -> roughness).

§metallic_invert: bool

Invert the metallic channel of a split map.

§displacement_scale: f32

Parallax occlusion mapping strength for the displacement map (0 = off).

§reflection_intensity: f32

Per-material reflection strength (1 = full, 0 = matte/no reflections). Scales BOTH the environment-cube probe reflection and the screen-space / ray-traced reflection for this material, so reflection technique + look can be mixed and matched per material without changing the global model.

§screen_reflections: bool

Per-material screen-space / ray-traced reflection toggle. When false this material still gets the environment / reflection-probe CUBE reflection but the deferred SSR/RT resolve skips it (reflectivity 0 in the G-buffer) — so reflection TECHNIQUE can be mixed per material (cube-only vs cube + SSR/RT).

§reflection_mode: SurfaceReflection

Per-material reflection mode: the environment’s global technique, baked probes only, or none. (Planar mirrors come from the object’s Planar Reflection component, not from the material.)

§albedo_tiling: [f32; 2]

Per-texture UV tiling (xy scale, default 1) + offset (default 0) for the main maps; masks follow their parent map. UV scale for the albedo map (default 1).

§albedo_offset: [f32; 2]

UV shift for the albedo map (default 0).

§normal_tiling: [f32; 2]

UV scale for the normal map.

§normal_offset: [f32; 2]

UV shift for the normal map.

§orm_tiling: [f32; 2]

UV scale for the ORM map.

§orm_offset: [f32; 2]

UV shift for the ORM map.

§emission_tiling: [f32; 2]

UV scale for the emission map.

§emission_offset: [f32; 2]

UV shift for the emission map.

§matcap_strength: [f32; 3]

Additive matcap layer strengths (0 = off). Matcap textures are assigned via the .material file’s texture slots.

§matcap_blend: [MatcapBlend; 3]

Per-layer matcap blend mode (how each layer combines with the colour).

§render_queue: i32

Draw-order priority (Unity render queue): Geometry 2000, AlphaTest 2450, Transparent 3000, Overlay 4000.

§detail: DetailModel

Detail albedo / normal / ORM layer.

§transmission: TransmissionModel

Thin translucency + see-through transmission.

§tess: TessellationModel

Tessellated displacement (the Displacement texture is the height map).

§textures: MaterialTexturePaths

Per-slot texture assignments (project-relative). Editable in the inspector; resolved to GPU handles when the material is applied.
