Struct Bindings 

Source 
pub struct Bindings {
    pub schemes: Vec<ControlScheme>,
    pub active: usize,
    pub auto_switch: bool,
    pub version: u32,
}
Expand description

All control schemes for a project + the active one. Serialized to project.zestengine (so it survives reloads) and editable at runtime.

Fields§

§schemes: Vec<ControlScheme>

All schemes.

§active: usize

Index of the active scheme.

§auto_switch: bool

Follow the device in use: the VR scheme while a headset runs, else whichever of keyboard + mouse / gamepad was touched last.

§version: u32

Format revision; older files are upgraded by Bindings::upgrade.

pub fn rebind( &mut self, scheme: &str, action: &str, slot: BindingSlot, index: usize, source: InputSource, policy: ConflictPolicy, ) -> Result<Vec<String>, RebindError>

Bind source at index of slot on action in scheme (“” = the active one), replacing what was there. Binding a stick axis to the analog X of a 2D action also binds its Y partner. Other actions using the input are handled by policy; returns the actions it changed.
