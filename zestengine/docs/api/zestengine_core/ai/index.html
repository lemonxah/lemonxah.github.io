AI behaviour trees and perception.

The behaviour tree is a data-driven node graph evaluated against a shared Blackboard. Starter node set: Sequence, Selector, Condition and Action leaves (plus Invert and the constant Success / Failure leaves). Native systems update perception before ticking behaviour trees; action leaves read and write typed ECS values and defer emitted events.

Perception is a separate Perception component: a vision cone plus a ray-cast through the engine’s physics queries, written into the blackboard for conditions to read. The .behaviour asset format (RON) lives in zestengine-assets and wraps the same BtNode graph.

BehaviourTreeAgent
Runs a behaviour tree every frame. The tree is stored inline (the same BtNode RON the .behaviour asset wraps); asset is the project-relative .behaviour path the editor opens, and a future increment reloads it.
Blackboard
Shared blackboard a tree reads each tick. Conditions read values; the agent seeds it from perception; action leaves use it for their parameters.
BlackboardEvent
A gameplay event an BtAction::Emit leaf broadcasts.
Perception
Vision and hearing senses for AI perception.
PerceptionComponent
Component that detects other objects through a vision cone (ray-cast against the physics world) and a hearing sphere. The owning BehaviourTreeAgent reads the result into its blackboard as has_target, target_id and target_position.
PerceptionState
The last target the owning Perception component detected.
