Expand description

Continuously editable material parameters; delivered to the shader as push constants every draw, so edits are live with zero sync hazards.

Fields§

§base_color: [f32; 4]

Base albedo, linear RGBA; the alpha is used by transparent materials.

§emission_color: [f32; 3]

Emissive colour, linear RGB (only meaningful when the emission map or intensity makes it visible).

§emission_intensity: f32

Multiplier on the emission colour / map (0 = off).

§emission_map_mean: [f32; 3]

Mean LINEAR RGB of the emission map (1,1,1 = no map). Scales the per- instance emission fed to the RT reflection + RT GI gather so a mostly-black map (e.g. only a glowing visor) doesn’t make the whole mesh reflect/bounce as a uniform light. The per-pixel forward emission is unaffected (it samples the actual map).

§metallic: f32

Metalness 0 (dielectric) .. 1 (metal).

§roughness: f32

Perceptual roughness 0 (mirror) .. 1 (diffuse).

§toon_steps: f32

Toon cel-shading band count (1 = flat).

§pbr_toon_blend: f32

Blend between PBR and toon shading, 0 = PBR .. 1 = toon.

§alpha_cutoff: f32

Alpha-test threshold 0..1 for cutout materials.

§normal_strength: f32

Normal-map intensity (0 = off).

§occlusion_strength: f32

Ambient-occlusion map strength (0 = off).

§rim_color: [f32; 3]

Toon rim-light colour.

§rim_power: f32

Toon rim Fresnel exponent (higher = tighter edge).

§rim_strength: f32

Toon rim strength (0 = off).

§ramp_smoothness: f32

Toon cel-ramp edge softness.

§base_scroll: [f32; 2]

Animated UV scroll for the base maps (uv units / second).

§emission_scroll: [f32; 2]

Animated UV scroll for the emission map.

§emission_pulse: f32

Emission pulse speed (0 = steady); brightness oscillates.

§matcap_strength: [f32; 3]

Additive matcap strengths (3 layers; 0 = off). Each layer samples its own matcap texture, multiplied by its mask.

§matcap_blend: [f32; 3]

Per-layer matcap blend mode encoded as a float: 0 = Add, 1 = Multiply, 2 = Replace.

§albedo_tiling: [f32; 2]

UV scale for the albedo map (Unity tiling; default 1).

§albedo_offset: [f32; 2]

UV shift for the albedo map (default 0).

§normal_tiling: [f32; 2]

UV scale for the normal map.

§normal_offset: [f32; 2]

UV shift for the normal map.

§orm_tiling: [f32; 2]

UV scale for the ORM map.

§orm_offset: [f32; 2]

UV shift for the ORM map.

§emission_tiling: [f32; 2]

UV scale for the emission map.

§emission_offset: [f32; 2]

UV shift for the emission map.

§ao_invert: bool

Invert the AO channel of a split ORM map.

§roughness_invert: bool

Invert the roughness channel (e.g. a smoothness map).

§metallic_invert: bool

Invert the metallic channel.

§displacement_scale: f32

Parallax occlusion mapping strength (uv shift at full height). 0 = off.

§reflection_intensity: f32

Per-material reflection strength (1 = full, 0 = matte). Scales the env-cube probe reflection AND the screen-space/RT reflection for this material.

§screen_reflections: bool

Per-material screen-space/RT reflection toggle (true = on). Off keeps the env-cube reflection but skips the deferred SSR/RT resolve for this material.

§reflection_mode: u8

Per-material reflection mode: 0 = the environment’s global technique, 2 = baked probes only (no SSR / ray-traced resolve), 3 = none. Mirrors zestengine_core::ReflectionMode for the shader (fx.parallax.w).

§detail: DetailParams

Detail layer (albedo / normal / ORM tiled over the base maps).

§transmission: TransmissionParams

Thin-surface translucency and see-through transmission.

§tess: TessParams

Tessellation + height-map displacement (hardware tessellation stages).
