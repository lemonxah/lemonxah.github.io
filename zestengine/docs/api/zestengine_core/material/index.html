Module material 

Source
Expand description

Continuously editable material parameters: the single block of data that describes how a surface shades. Plugins read and write materials through this type (see crate::ecs::EcsMoveHost::material_params and crate::ecs::EcsMoveHost::modify_material), so it lives in core where plugins link.

Structs§

DetailParams
Standard-shader detail layer: a second set of albedo, normal and ORM maps sampled at their own tiling, gated by a mask. Every strength is 0 by default, which switches the layer off (old materials load unchanged).
MaterialParams
Continuously editable material parameters; delivered to the shader as push constants every draw, so edits are live with zero sync hazards.
TessParams
Displacement through hardware tessellation (UNITY-12): the mesh’s triangles are subdivided by their screen-space edge length and the new vertices pushed along the (Phong-smoothed) normal by the material’s height map (the Displacement texture slot, white = peak). Off by default; a material without it pays nothing (its pipelines have no tessellation stages). Needs a device with tessellationShader; elsewhere the material draws flat (use parallax mapping).
TransmissionParams
Standard-shader translucency (light through a thin surface, leaves / paper / cloth) and transmission (the scene behind a see-through surface, glass / thin plastic). Both default to 0 = off.
