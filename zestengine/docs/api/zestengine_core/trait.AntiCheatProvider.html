Expand description

An anti-cheat product. One object serves one process: a game client uses the client_* methods, a dedicated server the server_* ones. Payloads are opaque to the engine (at most MAX_PAYLOAD bytes each) and are delivered reliably and in order over the signed session.

fn server_provider_id(&self, _client: u64) -> Option<String>

A stable id the provider has for this client’s account or machine (an EOS product user id, a Steam id …), once it is known. The server links it to the player id so a ban also covers the account: a new key on the same account stays banned. None = the provider has no such id (the default, and the null provider).
