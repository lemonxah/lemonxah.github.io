Module cloth_contact 

Source
Expand description

Swept cloth contact primitives. Conservative advancement uses a bound on relative feature speed, not a fixed number of time samples. Queries that exhaust their iteration budget return a conservative contact at the last proven-safe time rather than silently accepting a possible crossing.
