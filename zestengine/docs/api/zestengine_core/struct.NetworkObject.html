Expand description

Marks an object as networked: a stable network identity (the object id, shared by every peer that loads the scene, or the id chosen by the spawner for runtime spawns), an owner, and what replicates.

Fields§

§ownership: OwnershipMode

How ownership may change hands.

§sync_transform: bool

Replicate the object’s position and rotation.

§sync_scale: bool

Replicate the object’s scale.

§sync_rigidbody: bool

Owner simulates the Rigid Body; other peers make it kinematic and follow.

§sync_parent: bool

Replicate parent changes.

§sync_active: bool

Replicate active / inactive state.

§send_rate: f32

Transform updates per second.

§interpolation: InterpolationMode

How non-authority peers show the replicated transform.

§interp_delay: f32

Seconds remote peers render behind the newest snapshot.

§position_threshold: f32

Skip sends while the object moved less than this (meters).

§rotation_threshold: f32

Skip sends while the object turned less than this (degrees).

§relevancy: f32

Only replicate to players within this distance (0 = everyone).

§always_relevant: bool

Interest management (dedicated servers): every client is told about this object whatever the distance (managers, scoreboards, the sun).

§despawn_on_owner_leave: bool

Remove the object when its owner leaves (otherwise it becomes unowned).

§quantize: bool

Pack positions into 24 bits per axis (1 mm, +-8 km) and rotations into 32 bits.

§adaptive_delay: bool

Grow the interpolation delay above interp_delay when the measured jitter and loss need it (and shrink back when the link calms down).

§predicted: bool

Server-authoritative movement with client-side prediction, for a crate::Pawn, First / Third Person Controller or VR Player (any crate::Predictable): the owner moves at once from its own input and sends the inputs; the host simulates the controller from them and replies with the authoritative state, which the owner reconciles with (rewind + replay, smoothed). Everyone else interpolates the host’s state.

§state: NetObjectState

Runtime replication state the engine writes each frame (not saved).
