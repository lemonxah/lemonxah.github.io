Crate zestengine_core 

Source
Expand description

zestengine-core: the engine-runtime API shared by the engine, editor, and plugins. Egui-free by design so a shipped game links it (through the engine) without pulling in any editor code.

Holds serializable Component/TypedComponent data, native ECS systems registered on ComponentRegistry, Transform, deferred ComponentCommands, and the built-in component data. Editor-only concerns (inspector UI, viewport gizmos) are separate traits in zestengine-editor. Typed ECS storage, hierarchy and plugin system registration live in ecs.
