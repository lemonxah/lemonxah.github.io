Expand description

A controllable entity (pawn + player-controller combined). When possessed, it reads the action snapshot, moves itself, drives + activates its camera, and (FP/TP) writes the child camera’s pitch / spring-arm. With a CharacterController on the same object it walks through the physics world (walls, steps, slopes); without one it moves on a flat floor at its start height.

The local player controls this pawn (it receives input + owns the view).

Camera object this pawn drives/activates. For FP/TP make it a CHILD of the pawn so body yaw rotates it; the pawn writes its local pitch / arm offset.

§spawn_tag: String

If set, the pawn teleports to a matching SpawnPoint on Play start.

pub fn step( &mut self, input: &InputState, dt: f32, pos: &mut Vec3, physical: Option<bool>, view: Option<(f32, f32)>, ) -> Option<Vec3>

One movement step from an input frame (dt is the frame’s scaled delta). view replaces the look input with a recorded (yaw, pitch). physical is Some(grounded) when a Character Controller moves the pawn: the returned world delta goes to move_character. Otherwise the pawn walks a flat floor and pos (local translation) moves in place.
