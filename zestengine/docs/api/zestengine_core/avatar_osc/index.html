/avatar/parameters OSC bridge: the address mapping, the declared-only input filter and the message encoder, with no sockets (the engine owns those, see face_input.rs).

The convention is VRChat’s, so existing tools work: a parameter Hat is /avatar/parameters/Hat; tools send to UDP 9000 and listen on 9001; the bridge announces the worn avatar with /avatar/change <id>. Input is limited to the parameters the avatar declares: engine built-ins (IsLocal, Grounded, …) and unknown names are ignored, so a tool cannot fake what the engine measures. Each parameter accepts at most 60 writes a second; the newest value that was held back is released on the next poll, so a sweep always ends on its last value.
